# Interactive Plant Light Sculptures Workshop
## Session Summary (4 evenings, 5:00-9:00 PM)

---

## **SESSION 1: Arduino & Sensors**

**Main Activities:**
- Arduino basics: Programming fundamentals, upload first program (Blink), understand setup() and loop()
- Wire up ultrasound sensor, read values via Serial Monitor
- Connect WS2812 LED strip, control colors, experiment with different effects
- Quick intro to combining sensor + LEDs for reactive brightness/color
- Explore advanced LED animations: rainbow, color palettes, temporal effects, spatial patterns
- Browse 3D plant parts library, select pieces for overnight printing

**Deliverable:** Sensor-reactive LED code saved

---

## **SESSION 2: Code Polish & 3D Design**

**Main Activities:**
- Collect overnight prints
- Code workshop: refine behaviors, optimize performance, add multiple modes
- Instructor mini-lectures: FastLED optimization, sensor calibration, power budgets
- Tinkercad tutorial: import, scale, modify 3D models
- Customize plant parts: bases, stems, leaves, decorative elements
- Submit final 3D designs for overnight printing
- Test power supply (battery or wall adapter)

**Deliverable:** Polished code + custom 3D designs submitted

---

## **SESSION 3: Assembly**

**Main Activities:**
- Collect final prints
- Dry fit all components (NO GLUE) - get instructor approval
- Mount Arduino, route LED strips, organize wiring
- Hot glue structural assembly (supervised station)
- Cable management with zip ties
- Complete system testing: code + power + mechanical stability
- "ER Clinic" troubleshooting for any issues

**Deliverable:** Fully assembled, working light sculpture

---

## **SESSION 4: Showcase**

**Main Activities:**
- Final polish and testing
- Setup showcase display area
- Prepare 3-minute presentations (concept, technical, design decisions, future)
- **Lightning presentations** - each group presents at their station
- **Gallery walk** - explore all projects, detailed Q&A
- **Group critique** - discuss challenges, solutions, learnings
- Awards ceremony (8 categories: creative design, light effects, troubleshooting, innovation, collaboration, improvement, sensor integration, instructor's choice)
- Group reflection and feedback

**Deliverable:** Presentation + finished interactive sculpture

---

**Time per session:** 4 hours  
**Total workshop:** 4 sessions  
**Final output:** Interactive plant light sculpture with custom code + 3D printed parts
