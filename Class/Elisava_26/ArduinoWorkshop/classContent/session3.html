Dry Fit First! 🧩

Test EVERYTHING before gluing

Why Dry Fit Matters

Without Dry Fit:

  • Glue everything together
  • Discover Arduino doesn't fit
  • Cry 😭

With Dry Fit:

  • Test fit everything
  • Find problems early
  • Fix BEFORE glue!

📋 Dry Fit Checklist

  • Arduino fits in base with room for wires
  • Breadboard placement (if using)
  • LED strip routes through stems/structure
  • Power supply has mounting location
  • All 3D parts fit together as intended
  • Wire lengths are adequate
  • Access to USB port for reprogramming

Electronics Integration ⚡

Making it all work together

The Golden Rule

TEST AT EVERY STEP!

Power on → Verify → Then proceed

If something breaks, you'll know exactly when!

Electronics Integration Steps

  1. 1 Position Arduino in base → Test
  2. 2 Route LED strip through structure → Test
  3. 3 Position sensor → Test
  4. 4 Connect power supply → Test
  5. 5 All working? → Secure with tape/ties

Cable Management 🔌

  • Use zip ties to bundle wires
  • Leave some slack (stress relief!)
  • Route away from moving parts
  • Keep USB port accessible

Structural Assembly 🔧

Hot glue time!

🔥 Hot Glue Station Protocol

  • Only at designated supervised station
  • Let gun heat fully (3-5 minutes)
  • Hot glue BURNS! Don't touch fresh glue

Gluing Technique

  1. Plan - Know exactly what you're joining
  2. Apply glue - Small amount, one surface
  3. Press together - Hold 10-15 seconds
  4. Wait - 30 seconds before handling
  5. Clean up - Remove glue strings immediately

💡 Less is more! Excess glue is messy and weak

Assembly Checkpoints

Test after each major operation:

  • ✓ After securing Arduino → LEDs still work?
  • ✓ After attaching stems → Sensor still reads?
  • ✓ Before final assembly → Last chance to fix!
  • ✓ Final test → Everything functioning?

If Something's Broken...

  1. Don't panic! 😮‍💨
  2. Isolate the problem: Code? Wiring? Mechanical?
  3. Test components individually
  4. Ask for help immediately

Most issues are simple to fix once identified!

Quick Troubleshooting Guide

LEDs not lighting?

Check power, data wire, arrow direction

Sensor not reading?

Check wiring, open Serial Monitor

Dim on battery?

Battery low, or too many LEDs at max brightness

Code won't upload?

Check port selection, try different USB cable
