Arduino 101

Let's understand the hardware

What is Arduino?

  • Microcontroller - tiny computer on a chip
  • + Convenient IDE - easy programming environment
  • + Vast ecosystem - libraries, sensors, shields

Understanding GPIO Pins

Digital

HIGH (5V) or LOW (0V)

Perfect for: LEDs, buttons

Analog

Values: 0-1023

Perfect for: sensors

PWM (~)

Fake analog output

Perfect for: dimming

Arduino Programming Model


void setup() {
    // Runs ONCE when Arduino starts
}

void loop() {
    // Runs FOREVER, over and over
}

Think of it like:

  • setup() = Initialize your program
  • loop() = while(true) { ... }

The Classic: Blink LED 💡

Every programmer's "Hello World"


void setup() {
    pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
    digitalWrite(LED_BUILTIN, HIGH);
    delay(1000);
    digitalWrite(LED_BUILTIN, LOW);
    delay(1000);
}

WS2812 LEDs 💡🌈

Individually addressable RGB magic

What Makes Them Special?

Regular LEDs:

  • One wire per LED
  • All same color
  • All on/off together

WS2812 (NeoPixels):

  • ONE data wire for all!
  • Each LED = any RGB color
  • Individual control
  • Daisy-chained

Wiring WS2812 LEDs

⚠️ Arrow direction matters! Data flows ONE WAY →

Red → 5V  |  Black → GND  |  Yellow → Pin 6

Turn LEDs On!


#include <FastLED.h>

#define NUM_LEDS 10
#define DATA_PIN 6

CRGB leds[NUM_LEDS];

void setup() {
    FastLED.addLeds<WS2812, DATA_PIN, GRB>(leds, NUM_LEDS);
}

void loop() {
    leds[0] = CRGB::Red;  // First LED = red
    FastLED.show();        // Update the LEDs!
}

Understanding the Code


CRGB leds[NUM_LEDS];              // Array of color values
leds[0] = CRGB::Red;              // Set color (in memory)
FastLED.show();                    // Send to physical LEDs

Think of it like:

  1. You have a canvas (the array)
  2. You paint on the canvas (set colors)
  3. You display the canvas (FastLED.show())

Exploring Colors 🎨


// Named colors
leds[0] = CRGB::Red;
leds[1] = CRGB::Green;
leds[2] = CRGB::Blue;

// RGB values (0-255 each)
leds[3] = CRGB(255, 128, 0);  // Orange

// HSV - easier for rainbows!
leds[4] = CHSV(160, 255, 255);

Why HSV is Your Friend

RGB

Mix red, green, blue

Hard to make rainbows

HSV

Hue (color) 0-255

Saturation · Value

Change only the hue to cycle through the rainbow: CHSV(hue++, 255, 255)

LED Patterns 🌊

Let's make some magic!

Rainbow Generation


void loop() {
    static uint8_t hue = 0;

    for(int i = 0; i < NUM_LEDS; i++) {
        leds[i] = CHSV(hue + (i * 10), 255, 255);
    }

    FastLED.show();
    hue++;  // Slowly rotate colors
    delay(20);
}

static = variable persists between loop calls

Using Palettes


void loop() {
    static uint8_t startIndex = 0;
    startIndex++;  // Motion speed

    for(int i = 0; i < NUM_LEDS; i++) {
        leds[i] = ColorFromPalette(OceanColors_p,
                                    startIndex + i * 4);
    }

    FastLED.show();
    delay(20);
}

Try swapping OceanColors_p for other palettes!

Wave / Chase
