LEDs WS2812 💡🌈

Magia RGB direccionable individualmente

¿Qué los Hace Especiales?

LEDs Normales:

  • Un cable por LED
  • Todos del mismo color
  • Todos encendidos/apagados juntos

WS2812 (NeoPixels):

  • ¡UN cable de datos para todos!
  • Cada LED = cualquier color RGB
  • Control individual
  • Conectados en cadena

Cableado de LEDs WS2812

⚠️ ¡La dirección de la flecha importa! Los datos fluyen en UN SENTIDO →

Rojo → 5V  |  Blanco → GND  |  Verde → Pin 6

¡Enciende los LEDs!


#include <FastLED.h>

#define NUM_LEDS 10
#define DATA_PIN 6

CRGB leds[NUM_LEDS];

void setup() {
    FastLED.addLeds<WS2812, DATA_PIN, GRB>(leds, NUM_LEDS);
}

void loop() {
    leds[0] = CRGB::Red;  // Primer LED = rojo
    FastLED.show();        // ¡Actualiza los LEDs!
}

Entendiendo el Código


CRGB leds[NUM_LEDS];              // Array de valores de color
leds[0] = CRGB::Red;              // Establece el color (en memoria)
FastLED.show();                    // Envía a los LEDs físicos

Piénsalo así:

  1. Tienes un lienzo (el array)
  2. Pintas en el lienzo (estableces colores)
  3. Muestras el lienzo (FastLED.show())

Explorando Colores 🎨


// Colores nombrados
leds[0] = CRGB::Red;
leds[1] = CRGB::Green;
leds[2] = CRGB::Blue;

// Valores RGB (0-255 cada uno)
leds[3] = CRGB(255, 128, 0);  // Naranja

// HSV - ¡más fácil para arcoíris!
leds[4] = CHSV(160, 255, 255);

Por Qué HSV es Tu Amigo

RGB

Mezcla rojo, verde, azul

Difícil hacer arcoíris

HSV

Hue (matiz) 0-255

Saturation · Value

Cambia solo el matiz para ciclar a través del arcoíris: CHSV(hue++, 255, 255)

Generación de Arcoíris


void loop() {
    static uint8_t hue = 0;

    for(int i = 0; i < NUM_LEDS; i++) {
        leds[i] = CHSV(hue + (i * 10), 255, 255);
    }

    FastLED.show();
    hue++;  // Rota lentamente los colores
    delay(20);
}

static = la variable persiste entre llamadas de loop

void loop() {
    static uint8_t startIndex = 0;
    startIndex++;  // Velocidad de movimiento

    for(int i = 0; i < NUM_LEDS; i++) {
        leds[i] = ColorFromPalette(OceanColors_p,
                                    startIndex + i * 4);

    delay(20);
}
