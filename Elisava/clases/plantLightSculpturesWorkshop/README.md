# Plant Light Sculptures Workshop

ELISAVA workshop materials for creating interactive LED sculptures with Arduino.

## Session Files

Open these HTML files in any browser. They're self-contained Reveal.js presentations.

| File | Topic |
|------|-------|
| **session1.html** | Intro & safety, 3D printing basics, part selection, Arduino fundamentals, AI-assisted coding, WS2812 LEDs |
| **session2.html** | Print reveal, Tinkercad 3D modeling, ultrasound sensor wiring, distance-based interactivity |
| **session3.html** | Custom print pickup, dry fit assembly, electronics integration, hot glue techniques, troubleshooting |
| **session4.html** | Final polish, showcase presentations, gallery walk, group critique, awards |

## Usage

Just double-click any session HTML file to open it in your browser. Use arrow keys to navigate slides.
