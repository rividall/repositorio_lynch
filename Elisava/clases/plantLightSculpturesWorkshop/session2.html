HC-SR04 Ultrasound Sensor

How it works:

  • Sends ultrasonic pulse (like a bat!)
  • Measures time for echo to return
  • Distance = time × speed of sound

Wiring the Sensor

VCC → 5V  |  GND → GND  |  TRIG → Pin 9  |  ECHO → Pin 10

Reading Distance


#define TRIG_PIN 9
#define ECHO_PIN 10

void setup() {
    Serial.begin(9600);
    pinMode(TRIG_PIN, OUTPUT);
    pinMode(ECHO_PIN, INPUT);
}

void loop() {
    long distance = getDistance();
    Serial.print("Distance: ");
    Serial.println(distance);
    delay(100);
}

The Distance Function


long getDistance() {
    // Send pulse
    digitalWrite(TRIG_PIN, LOW);
    delayMicroseconds(2);
    digitalWrite(TRIG_PIN, HIGH);
    delayMicroseconds(10);
    digitalWrite(TRIG_PIN, LOW);

    // Measure echo time
    long duration = pulseIn(ECHO_PIN, HIGH);

    // Convert to centimeters
    return duration * 0.034 / 2;
}

Open Serial Monitor to see values!

The Magic of map()


// Convert sensor range to LED range
int brightness = map(distance, 5, 100, 255, 0);
//                   value     from   to    output range

Translates:

  • Distance 5cm → brightness 255 (bright)
  • Distance 100cm → brightness 0 (off)

Reactive Light Systems 🌈

Sensor + LEDs = Magic

Basic: Distance → Brightness


void loop() {
    long distance = getDistance();

    // Map distance to brightness (closer = brighter)
    int brightness = map(distance, 5, 100, 255, 50);
    brightness = constrain(brightness, 50, 255);

    // Apply to all LEDs
    for(int i = 0; i < NUM_LEDS; i++) {
        leds[i] = CHSV(160, 255, brightness);
    }
    FastLED.show();
}

🟢 Beginner Start here!

Intermediate: Distance → Color


void loop() {
    long distance = getDistance();

    // Map distance to hue (color wheel position)
    int hue = map(distance, 5, 100, 0, 255);
    hue = constrain(hue, 0, 255);

    // Rainbow based on distance!
    fill_solid(leds, NUM_LEDS, CHSV(hue, 255, 200));
    FastLED.show();
}

Expert: Multi-Zone Control


void loop() {
    long distance = getDistance();

    if(distance < 20) {
        // Very close: Bright warm white
        fill_solid(leds, NUM_LEDS, CRGB(255, 200, 150));
    } else if(distance < 50) {
        // Medium: Flowing ocean
        runOceanPattern();
    } else {
        // Far: Calm breathing purple
        uint8_t breath = beatsin8(15, 50, 150);
        fill_solid(leds, NUM_LEDS, CHSV(200, 255, breath));
    }
    FastLED.show();
}

🔴 Expert Different behaviors per zone!

Pro Tip: Smooth Your Readings


// Global variable to store smoothed value
int smoothedDistance = 50;

void loop() {
    long rawDistance = getDistance();

    // Smooth: mix 90% old + 10% new
    smoothedDistance = (smoothedDistance * 9 + rawDistance) / 10;

    // Use smoothedDistance instead of raw
    int brightness = map(smoothedDistance, 5, 100, 255, 50);
    // ...
}

Eliminates jittery/noisy readings!
