# Sacred Project Structure

This is a kid's reader app. We will create and test everything on a Macbook Pro running BigSur 11.7 (Except for the audio INPUT)

## Sacred Objects

**Sacred Architecture:** UI screens and logic flow (Splash, Home, Level, Story, MiniGames, etc.)
**Sacred Project Folder:** Folder and file structure used across the project.
**Sacred System Config:**
- Raspberry Pi 7" Touch Display v1.1
- USB Serial Communication with ESP32
- speech_recognition library
- VLC for MP3 playback
